# Du behältst die Kontrolle

PHI47 fragt, bevor er eingreift.

- **Bevor** eine Datei geschrieben oder ein Befehl ausgeführt wird, erscheint eine Karte mit **Weiter** oder **Abbrechen**.
- Geänderte Dateien landen zuerst als **Vorschlag** im Editor: Zeile für Zeile ansehen, dann **annehmen** oder **verwerfen**.
- **Rückgängig** funktioniert wie gewohnt mit **Strg+Z**.
- Während gearbeitet wird, siehst du es: Der Rahmen leuchtet, die Statusleiste zeigt „Agent arbeitet …" oder „Kommando läuft …".

Wenn du zügiger vorankommen willst, stell die Einstellung **Freigabe-Modus** auf `auto` — dann arbeitet PHI47 ohne Rückfragen durch. Für den Anfang empfehlen wir `review`.
