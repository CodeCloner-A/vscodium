# Sag, was entstehen soll

Der Chat ist die Kommandozentrale — **Strg+Alt+I** öffnet ihn.

Unten im Eingabefeld sitzen zwei Auswahlfelder:

- **Modus** — wie PHI47 vorgeht:
  - **Agent** — baut sofort los: liest, schreibt, führt aus.
  - **Plan** — fragt das Nötigste und liefert einen Plan zum Abnicken.
  - **Erweiterter Plan** — interviewt dich gründlich, eine Frage nach der anderen, bis alles geklärt ist. Danach genügt ein Klick auf **Plan umsetzen**.
- **Modell** — welche KI antwortet.

Beispiele zum Ausprobieren:

- *Bau mir eine Notizen-App mit Suchfunktion.*
- *Warum schlägt mein Build fehl?*
- *Verschaff dir einen Überblick über dieses Projekt.*
