# Ein Projekt öffnen

Ein Projekt ist einfach ein **Ordner auf deinem Computer**. Alles, was PHI47 für dich baut, liegt darin — und der Agent arbeitet ausschließlich dort. Außerhalb dieses Ordners fasst er nichts an.

Zwei Wege:

- **Neu anfangen:** Der Knopf legt einen frischen Ordner unter `Dokumente\VSCodium-Projekte` an und öffnet ihn.
- **Vorhandenes Projekt:** Menü **Datei → Ordner öffnen…**

> Ganz ohne Ordner kannst du dich weiter mit PHI47 unterhalten — Fragen stellen, Dinge erklären lassen. Nur bauen kann er dann nichts.
