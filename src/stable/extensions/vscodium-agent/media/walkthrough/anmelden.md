# Anmelden

PHI47 bringt seine KI mit — du brauchst **keine API-Schlüssel, keine Kreditkarte im Editor, keine Konfiguration**. Einmal mit Google anmelden, fertig.

Was dabei passiert:

- Der Browser öffnet sich kurz, du wählst dein Google-Konto.
- Danach steht dir die Modellauswahl offen: die Gemini-Familie und weitere Modelle.
- Deine Anmeldung bleibt gespeichert — das ist ein einmaliger Schritt.

> Ohne Anmeldung bleibt der Chat stumm: Der Dienst gibt ohne Konto keine Modelle heraus.
